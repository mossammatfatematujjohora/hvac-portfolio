# HVAC Portfolio Website — Fatema Tuj Johora

A responsive, one-page portfolio website focused on HVAC contractors and local service businesses.

## Preview
Open `index.html` in a modern web browser.

## Publish
You can upload this static site to GitHub Pages or Netlify, or use it as the design and copy guide to rebuild the page in Elementor on your existing WordPress site.

## Before publishing
1. Confirm the portfolio and demo links.
2. Change the Contact Me button to your actual Contact page or email address.
3. Connect a real contact form (Elementor Forms or another form handler) and test it.
4. Add genuine screenshots from your PDF if desired.
5. Keep Lone Star Comfort labeled as a self-initiated demo. Do not claim client results or verified live Google Ads attribution without evidence.
6. Review service descriptions so they match the work you can currently deliver.
